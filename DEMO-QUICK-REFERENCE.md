## 🎬 Recording Software Quick Start

### Option 1: OBS Studio (Recommended)
```
1. Open OBS Studio
2. Add source: "Display Capture"
3. Settings: 1920x1080, 60fps
4. Start Recording
5. Stop when done
```

### Option 2: Windows Game Bar (Fastest)
```
1. Press Win + G
2. Click Record button (or Win + Alt + R)
3. Record your demo
4. Stop with Win + Alt + R
```

### Option 3: Loom (Easiest)
```
1. Install Loom extension
2. Click "Start Recording"
3. Select "Full Screen"
4. Record with voiceover
5. Auto-uploads and shares
```
